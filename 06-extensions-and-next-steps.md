# Network structure and next steps

**Are pairwise interactions modeled independently?** The dominant paradigm — latent-factor / network-embedding link prediction (Poisot's case study; the "Netflix problem" framing, Desjardins-Proulx et al. 2017) — scores each pair, but each species' embedding is learned from *all* its interactions, so a generalist's many partners enter every prediction about it. Shared structure is captured through the representation, not by treating pairs as independent draws. Galiana's super-generalists are the same degree-heterogeneity phenomenon.

**PPE fits this and helps the many-species goal.** `Δ` factorizes: the plant flowering curve `f_P` is a plant-level object reused across all of P's pairs, `a_A` a pollinator-level object — so `Δ(P,A) = overlap(f_P, a_A)` is itself low-rank (per-plant phenology profile × per-pollinator activity profile). Sharper: pure network embeddings only work for species already in the interaction network (Poisot flags extending them to data-poor species as a needed "methodological breakthrough"); PPE supplies a phenology profile for *any* plant, interacting-or-not, so PPE-features extend predictions to cold-start species the embedding can't reach.

**What per-pair scoring does not capture:** global network structure — connectance, nestedness, degree distribution. Independent scoring can yield a predicted network that violates these. This is addressed elsewhere: Poisot's "predict the network and the interactions jointly" (constrain by connectance), Galiana's entire degree-distribution result, and joint models (JSDM/HMSC for the availability/co-occurrence fields — not their residual covariance as interactions, per Blanchet; stochastic block / nestedness-aware models on the interaction side). A recognized separate thread, not something the initial paper must solve.

**Cheap bridge (secondary analysis):** check whether adding PPE's temporal `Δ` shifts the *predicted* degree distribution toward Galiana's power-law. Spatial co-occurrence over-connects generalists; if phenological pruning corrects that, the predicted degree distribution should move toward the empirical power-law — a network-level validation of a pairwise feature, with no joint model required.

**Bigger-swing extension — spatiotemporal interaction-distribution modeling (SINR-style).** Reframe the whole problem as an SDM across space *and time* rather than matrix completion. SINR (Cole et al., ICML 2023) is the precedent: a shared implicit representation with per-species heads jointly maps ~47k species' ranges from presence-only data. PPE is effectively that idea extended to time and phenophase. The clean, scalable formulation: a shared spatiotemporal backbone gives each species an *active field* over `(ℓ,t)` — flowering for plants (PPE), activity for pollinators (a pollinator-SINR on GBIF) — and interaction opportunity for any pair is the spatiotemporal overlap of their two fields. This (a) amortizes structure across species via the shared backbone, addressing the independence concern natively; (b) is presence-only by construction, as SINR/SDMs are; (c) handles cold-start species; (d) keeps `Δ` but reframes it as "overlap of two temporal SDMs" rather than an ad-hoc feature. It scales because heads are per-species (plants + pollinators), not per-pair. Same caveats carry (pollinator data weak; opportunity ≠ strength). This is the more ML-novel framing and a strong standalone extension paper; the link-prediction-with-`Δ` version is the lower-risk initial paper.

*Validation without expert maps.* SINR *trains* on presence-only points; expert range maps are only its evaluation gold standard, and one of four benchmarks at that — so a SINR-like model here is buildable from point data alone (no expert maps required), and is graded the SINR way when maps are absent: presence-only metrics (Boyce / AUC-against-background on held-out co-observations) plus the spatial holdout, which is what distinguishes recovering real structure from refitting observation density. The asymmetry to exploit: of the two fields whose overlap defines opportunity, the *plant* field has an unbiased external gold standard — USA-NPN — so that half is anchored to clean truth (as in the main paper); the pollinator field and the interaction surface do not, so claims there rest on presence-only ranking, the spatial holdout, the divergence analysis (structural, not density-fit), and ideally a small expert-curated pollination network as a spot-check (the closest analog to an expert range map, for the interaction layer). Net: do not claim map-level recovery of a true opportunity surface; scope to opportunity and lean the argument on the NPN-anchored component. The approach rests, as SINR's does, on the method class being trustworthy when trained on biased points.
